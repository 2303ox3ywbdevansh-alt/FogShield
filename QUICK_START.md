# ⚡ FogShield on Railway - QUICK START (5 Minutes)

## 🎯 Go Live in 5 Steps

### **Step 1: Create GitHub Repo (1 min)**
```
1. Go to https://github.com/new
2. Name it: fogshield-hackathon
3. Make it PUBLIC
4. Click "Create repository"
```

### **Step 2: Add Files (1 min)**
```
Upload these files to your repo:
✓ fogshield-animated.html
✓ server.js
✓ package.json
✓ railway.json
✓ .gitignore
✓ README.md
```

### **Step 3: Push to GitHub (1 min)**
```bash
git add .
git commit -m "Initial commit"
git push origin main
```

### **Step 4: Deploy on Railway (1 min)**
```
Option A - Using Railway Web:
1. Go to https://railway.app
2. Click "Create New" → "Deploy from GitHub"
3. Select your fogshield-hackathon repo
4. Click Deploy
5. Wait 2-3 minutes...
6. Get your live URL! 🎉

Option B - Using Railway CLI:
npm install -g @railway/cli
railway login
cd your-project-folder
railway up
```

### **Step 5: Share & Impress! (1 min)**
```
Share this URL with judges:
👉 https://fogshield-xxxxx.railway.app
```
